# Retail Sales & Profitability Analysis

## Project Overview
This project analyzes 18,000+ retail transactions from 2022–2025 to evaluate sales performance, profitability, product performance, sales channels, regional trends, discounts, and returns.

The objective was to transform raw transactional data into meaningful business insights and develop an interactive dashboard for performance monitoring and decision-making.

## Tools Used
- Excel
- Power Query
- Power BI
- DAX

## Data Cleaning
The raw dataset contained several data quality issues. Using Power Query, I:
- Removed duplicate transaction records
- Handled missing Transaction IDs and product names
- Identified and treated invalid customer ages and quantities
- Corrected inconsistent region and categorical labels
- Handled invalid discount values
- Standardized categorical fields for analysis

## Analysis Performed
- Sales and profit trend analysis
- Category and product performance
- Sales channel analysis
- Regional performance
- Discount and profitability analysis
- Return analysis
- Average transaction value analysis

## Key Insights
- Sales increased by 19.9% in 2025 after declining in 2024.
- Electronics generated approximately 60% of total sales.
- B2B represented only about 12% of transactions but generated approximately 26% of sales.
- Profit margin declined from approximately 25% with no discount to 6.4% at a 20% discount.
- Changes in product mix contributed to a decline in average transaction value in 2023.

## Business Recommendations
- Review discounts above 15–20% due to significant margin erosion.
- Explore opportunities to expand the high-value B2B channel.
- Monitor the mix between high-value and lower-value products.
- Identify and build on the category and channel drivers behind the 2025 sales recovery.
